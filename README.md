# Kembara Kiblat Cilik

Permainan pembelajaran kiblat dengan kompas, kamera AI dan kuiz bernama.
Carta dikemas kini daripada Google Sheets setiap 10 saat semasa sambungan tersedia.
Setiap kuiz selesai disimpan melalui Google Apps Script. Markah dikira semula pada pelayan.
Google Sheet kekal peribadi kepada pemilik; nama panggilan dan markah pada carta boleh dilihat umum.

## Penerbitan
GitHub Pages: deploy dari branch `main`, folder `/ (root)`.
Gunakan HTTPS dan benarkan kamera untuk permainan tangan AI. Internet diperlukan untuk pustaka AI.

## Simpanan
Keputusan hanya ditanda berjaya selepas ID percubaan disahkan wujud di Google Sheets.
Jika sambungan gagal, rekod menunggu dihantar semula menggunakan ID yang sama bagi mengelakkan pendua.
Carta memaparkan sehingga 200 rekod tertinggi; semua rekod kekal dalam Google Sheet.
Ini ialah kuiz pembelajaran terbuka, bukan sistem peperiksaan dengan pengesahan identiti.
